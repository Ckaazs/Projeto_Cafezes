Projeto cafezes Aprendizagem em Desenvolvimento de Software 2026

O objetivo:
desse projeto erá criar um site funcional com 4 paginas funcionais sendo elas  home, sobre, produtos, contato com o tema de café sobre as observações e mentoria do professor Rickson Jordan.

Tecnologias utilizadas:
HTML, CSS, JavaScript.

Funcionalidades desenvolvidas
Aplicações desenvolvidas em HTML, CSS, JavaScript conexão com banco de dados mysql, gerenciamento de servidor com Aiven.

Como executar o projeto:
O projeto pode ser executado atravez da extenção "Live Server" que se adquiri dentro do Visual Studio Code na aba "Extenções".
